# EYT v0.2.0 - Experimental

EYT (Engineer Your Thing) is an open-source Agent Skill intended to help AI coding agents make more deliberate engineering decisions when building and reviewing web applications.

**This release updates EYT's instructions. It does not establish that agents using EYT produce better software.**

## What changed from v0.1.0

- **More concrete engineering guidance.** The core skill now gives conditional defaults and a repeatable process for choosing architecture, data ownership, UI states, trust boundaries and appropriate verification.
- **New failure-pattern reference.** Pairs common implementation smells with why they matter, a more reliable default and a check that can expose the problem. These are warning signs, not claims that every AI agent behaves this way.
- **New code-craft reference.** Shows TypeScript before-and-after examples for readable control flow, named values, cohesive responsibilities and reduced cognitive load. Readability is not reduced to line counts or formatting alone.
- **New end-to-end feature walkthrough.** Shows how to apply requirements, data handling, UI, architecture, failures and tests to one realistic feature without mandating a particular stack or layered architecture.
- **Expanded UI/UX guidance.** Adds more specific alternatives to generic visual templates, fabricated data, unclear hierarchy and missing loading/error/empty states while respecting approved designs.
- **More explicit security and verification checks.** Emphasizes per-account authorization, safe session handling, truthful save feedback, user-journey testing and the limits of build-only evidence.
- **Updated evaluation guidance.** Includes scenarios for code readability, browser auth flows and detecting unnecessary complexity.

The installable skill is still named `eyt`, with one `SKILL.md` and supporting references. The MIT license remains unchanged.

## Evidence and limitations

- v0.1.0 has **one informal, unreplicated, LLM-reviewed comparison** reported by a user. The full implementation source and raw execution traces were not independently audited in preparing EYT. That report is preliminary and cannot establish causality.
- **v0.2.0 has not been tested in a comparative coding-agent run.** No improvement in security, readability, accessibility, defect rate, or UI quality is claimed.
- Repository structural and link checks can verify the package, **not the effectiveness of the guidance**.
- EYT does not guarantee production readiness or replace engineering review, security testing or accessibility testing.

We welcome positive, negative and inconclusive evaluation results, including evidence that EYT adds unnecessary complexity. See [evaluation guidance](https://github.com/IshitRaj/eyt/blob/v0.2.0/evaluations/SCENARIOS.md), the [rubric](https://github.com/IshitRaj/eyt/blob/v0.2.0/evaluations/RUBRIC.md), and [origins and limitations](https://github.com/IshitRaj/eyt/blob/v0.2.0/docs/ORIGINS_AND_LIMITATIONS.md).

## Install or upgrade

Install or replace the full `skills/eyt/` directory according to the [README](https://github.com/IshitRaj/eyt/blob/v0.2.0/README.md#install-the-single-skill), including `references/`. Start a new agent session and confirm the skill actually loads. You do not need to rewrite existing applications just to adopt updated instructions.

**Status: experimental pre-release.** Feedback and independent reproduction are welcome.
